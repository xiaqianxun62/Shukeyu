# 账号与权限
关键词：登录, 注册, 密码, 改密码, 忘记密码, 重置密码, 微信登录, 昵称, 头像, 认证, 权限, 角色, 管理员, 账密

## 登录与注册
- 账号密码登录：账号 + 密码，登录成功后拿 JWT，默认 72 小时有效。
- 微信小程序登录：用微信 code 换 openid，首次登录自动建号，之后可绑定账号。
- 注册需要填账号、姓名、密码；昵称可后补，昵称不能与他人重复。

## 密码相关
- 修改密码：需要输入原密码 + 新密码，原密码不正确会被拒绝；改成功后旧 token 立即失效，需要重新登录。
- 管理员重置密码：管理员可以给指定用户重置为默认密码，用户登录后应尽快自行修改。
- 密码在服务端只存哈希（SHA-256 + 盐），任何接口都不会返回密码或哈希。

## 资料与认证
- 个人资料可以改昵称、性别、头像；昵称改动会同步影响积分榜展示名。
- 身份认证：系统随机抽一道密保问题，答对后标记为已认证；部分球局仅认证用户可见。
- 匿名球局报名只隐藏对外展示名，不会隐藏真实身份给管理员。

## 角色与权限（RBAC）
- 权限按「用户 → 角色 → 权限码」三层授予，接口按权限码校验，不再用 is_admin 布尔字段。
- 角色变更后按用户清缓存，下一次请求即生效。
- 普通成员只能改自己的资料、报名/取消自己的报名；管理员额外拥有赛事管理、用户管理、访问日志、球场字典等权限。
- 没有权限时返回 403，未登录返回 401。
